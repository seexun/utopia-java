# P2 前端迁移实现计划（jknow 迁移 · 阶段三）

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 把 utopia-web 的知识图谱前端能力移植进 jknow-web（若依 Vue3+TS 壳）——页面族落位 `views/knowledge/**`、走若依登录与动态路由、api 客户端切若依 token，vitest 32 spec（含 API 快照闸）修绿，UI 全功能走查通过；同时兑现 P1 落字的两项 P2 硬依赖（pt- 权限集展开 + @PreAuthorize 挂载 + entry point 适配裁定）。

**架构：** 若依 layout 为壳、V0100 菜单驱动业务页面路由（kb 详情动态路由进 constantRoutes）；utopia 的 api 层/组件/i18n/样式原样随迁，仅 client.ts 从 cookie 会话改造为若依 `Authorization: Bearer`；按钮级权限不上；utopia 自建 layout/登录页/守卫/platform-config/版本探针全部舍弃。

**技术栈：** Vue 3.5 / element-plus / pinia / vue-router / vue-i18n 11 / tailwindcss 4（@tailwindcss/vite）/ sigma+graphology / @tanstack/vue-query / vitest 4 / pnpm。
