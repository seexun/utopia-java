## 一、问题与修法

| | 改前 | 改后 |
|---|---|---|
| 层次 | 页灰(#F5F7FA) → 白卡 → 画布灰(#F5F7FA，**与页灰同色**) 三层套娃，读成"白卡开了个洞" | 页灰 → 细框 → 「白卡头 → 细线 → 画布 #FAFBFC」两段式 |
| 画布底 | `--color-bg`（复用页面灰） | 独立令牌 `--color-canvas`：亮 `#FAFBFC`（比页灰亮一档、比卡白暗一档）/ 暗 `#161616`（比页底深一档、比卡深两档） |
| 外层卡 | `.card` 整卡白底+阴影 | 背景透明、去阴影，仅留 1px 边框+圆角 |
| 卡头 | 继承卡片白底 | 显式 `bg-card`（卡片透明后两段式的白侧分界） |

改动面：`tokens.scss`/`tailwind.css` 各加令牌（亮+暗双档，双源同步）、`graph/index.vue`（卡头类+scoped 卡规则）、`graphVisuals.ts`（底色读新令牌×2、常量初值、**摊平纸底 `LIGHT_GROUND_RGB` 随画布走**）。
