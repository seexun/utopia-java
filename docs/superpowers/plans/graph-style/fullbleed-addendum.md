# 追加：工作区满铺定案（2026-11-25 晚）

页灰提亮（fcfcfd）后用户走查仍指向卡外的留白带+卡边框——**最终根因**：
.card 的 1px #E5EAF0 边框 + 8px 圆角 + .app-main 16px 外距在近白页上围出
可见矩形（边界感三件套）。

**定案（已实施，93844b8）**：图谱工作区页去 .card 外框/圆角/阴影/页外距
（:has 页级豁免 .app-main 留白），卡头贴侧栏与顶栏、画布满铺到底——
Figma/白板式「工具带 + 画布」，四周零框线。

实测（gs-probe6/7）：cardRect x=210（贴侧栏）y=92（贴 tags）w=1710 h=988
（到视口缘）；border none / radius 0 / shadow none；四侧 strip 均为卡片本体。
425/58 + typecheck + 双 smoke 全绿（同分支）。

## 结论留档
工作区型页面（图谱/本体）与卡片型页面（检索/文库/审查/系统管理）从此**分家**：
- 工作区型：满铺无框（本定案），本体页如需同款走 :has 同款豁免即可
- 卡片型：维持「页灰留白 + 白卡」，页灰 fcfcfd
## 教训
三轮迭代教训：用户对"灰"的感知 = **边界线**而非底色明度。给画布调底色/
点阵/框线都无法解决；答案是把边界撤掉。
