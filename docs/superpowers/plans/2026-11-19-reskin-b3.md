# 业务页重造·批次 3 实现计划（对话+本体+令牌清扫）

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 对话页（聊天流型）与本体页（双视图工作区型）照批次模板重造为 gvdata 观感（逻辑零动）+ 令牌清扫四项打包 + 批次零回归验收。

**架构：** 对话页=PageHeader+会话列表卡+消息流主卡+Composer 输入卡；本体页=PageHeader(视图切换)+表格/图示双视图（批次 2 包壳手法复用）+侧面板卡化+dialogs 走查驱动；清扫=StatusCell 删/pill 令牌/mark 形态双候选择优/搜索建议 max-height。

**技术栈：** Vue3 SFC/TSX / SSE（零动）/ el-table 全局 anivia / vitest。

## 全局约束

1. 逻辑零动铁律：两页 script 仅 import/纯展示 computed；SSE/会话路由/视图切换持久化/树分页/对话框表单逻辑全保留；markdown/citations/turn/steps/schema-graph 数据流零动。

3. SSE 验收不伪造：有 JKNOW_LLM_API_KEY 则真流，无则 UI 降级形态记录。
4. 环境：前端 80（baseUrl 19080 保留不提交）/后端 19080；`LC_ALL=C grep -a`。
