# 图谱页容器层次修正规格（白卡头+灰画布两段式，消三层套娃）

- 日期：2026-11-24
- 状态：已获用户批准（三方案呈现，用户选推荐方案一）
- 背景：国内风收口批（529af69）给画布铺了 `--color-bg` 灰底，但画布外已有白卡、卡外又是页面灰——形成「页面灰 → 白卡 → 画布灰」三层套娃，且画布灰与页面灰**同色**（均 #F5F7FA），视觉上像白卡开了个洞露出页面。用户反馈"外面有个灰色背景框不太好看"。

## 设计（方案一：白卡头 + 灰画布，两段式）

### §1 画布底换一档（消"同色开洞"）

- 画布底由 `--color-bg`（#F5F7FA，与页面灰同色）改为**独立画布令牌** `--color-canvas`：
  - 亮色：`#FAFBFC`（比页面灰亮一档、比纯白暗一档——夹在白卡头与页面灰之间，层次连续不跳）
  - 暗色：`#161616`（比页面 `#1a1a1a` 深一档、比卡 `#212121` 深一档，同向逻辑）
- 令牌落 `tokens.scss :root` + `html.dark`，并在 `tailwind.css` 注册（如需 utility）；`graphVisuals.ts drawWorldGrid` 的底色读 `--color-canvas`。
- **本体页 schema-graph 共用绘制层**：同批跟随换令牌（家族一致）。

### §2 外层白卡收敛为"框"（消套娃）

- `.graph-canvas-card` 不再整卡白底：背景改透明，仅保留 1px 边框 + 圆角 + overflow hidden（外框语义）。
- 卡头两行保持白底（`bg-card`）+ 底部分隔线；画布区由 §1 的画布底满铺。
- 结果：从上到下「白卡头 → 细线 → 灰画布」干净两段，四周一圈细框；页面灰只在卡片外侧留白带出现一次。

### §3 点阵对比度微调

- 画布底变亮一档后，点阵 alpha 相应下调（原 `GRID_MAX_ALPHA*3` → 实测目验定档，保持"静观无感、有纹理"）。

## 验收

1. 1280/1920 × 亮/暗 四截图：卡头白、画布 `#FAFBFC`（亮）/`#161616`（暗）、外圈细框、页面灰仅在外侧留白带；无"开洞"感。
2. 画布像素实测：亮 `250,251,252`、暗 `22,22,22`。
3. 本体页 schema-graph 同步（画布底同令牌）抽验一屏。
4. typecheck + `pnpm test`（425）+ `build:prod` 绿；console 零 error；主题切换两态画布重上妆不回归。

## 不做的事

- 不动卡头内容/行结构/控件；不动节点/边样式；不动其它页面（检索/文库/审查等卡片式页面保持整白卡）；不做方案三的"无卡片满铺"。
