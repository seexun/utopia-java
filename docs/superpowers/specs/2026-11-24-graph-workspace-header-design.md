# 图谱页工作区型页头合一规格（方案 A）

- 日期：2026-11-24
- 状态：已获用户批准（A/B 两案呈现，用户选 A）
- 背景：用户走查指出图谱页右侧主区"主标题位置很难看"——诊断为主标题带右侧 ~70% 留白 + 页头带与卡内工具行双头叠加 + 信息重复（副标题与侧栏 kb-switcher 同名）+ 三条横带挤压画布 ~80px。

## 设计（全部仅动 jknow-web/src/views/jknow/knowledge/graph/ 面，零逻辑改动）

### 1. 页头带取消，标题并入卡片头（核心）

- 删除独立 PageHeader（"图谱"大标题 + "演示：智造产业链"副标题整带）。
- 卡片第一行改为三段式：
  - 左段：`图谱` 标题（16-18px、粗体，不再是 24px 阅读型大标题）+ kb 名 chip（`演示：智造产业链`，badge-soft 形态，替代副标题；名称取自现有 kb 上下文，同名不重复出现在两处）。
  - 中段：搜索实体框 + 类型图例 chips（原卡内工具行内容保留，随行自适应；1280 视口若拥挤允许图例 chips 折行到第二行左对齐）。
  - 右段：统计胶囊（`18 个实体·24 条事实·23 条现行`，从画布右上浮动面板迁入；文本从 readiness/graph overview 数据派生不变）。
- 画布区域整体上移（页头带 ~80px 归还给画布）。

### 2. 画布浮动件收敛

- 移除画布右上角缩放 +/- 浮组（缩放保留左下工具组，去重复）。
- 边样式图例（事实/推断/推导/争议/未走通）保留右上位置但改半透明底+小尺寸，避让节点（不再盖"营收总额"等顶部节点）。
- 左下浮动工具列两组间距统一（视觉上成一组）。

### 3. 画布 fit 边距微调

- 顶部边距加大避免节点被卡头行裁切；右缘/底缘保持现有 fit 语义（此前批次已修，不回退）。

## 验收

1. 独立 Playwright 走查（DOM 断言先行）：1280 与 1920 双视口 × 亮/暗双主题四张截图——页头带消失、标题+kb chip+统计三段式在位、无浮动件盖节点、画布上移；console 零 error。
2. 登录→图谱功能不回归：搜索实体、图例 chips、缩放、时间轴拖动均可用（抽验交互各一）。
3. `pnpm typecheck` + `pnpm test`（425 基线）+ `pnpm build:prod` 绿；双 smoke 零退化。
4. 暗色主题下新卡片头/统计胶囊/半透明图例可读（截图证据）。

## 不做的事

- 不动标签栏"首页"口径——"首页=当前库图谱"是用户早期拍板的产品语义（首页选 A 决策），页内标题仍为"图谱"，两者并存是有意设计，不强行统一。
- 不动 PageHeader 组件本体（其它页面继续用）；不动本体页 schema-graph（本次范围仅图谱页；本体页如需同款另批）。
- 不动业务逻辑/数据流/路由；不做检索/审查等其它页的同款改造（后续按需另批）。
- 画布布局算法不动（fit 参数微调除外）。
