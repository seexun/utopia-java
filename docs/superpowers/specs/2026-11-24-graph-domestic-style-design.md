# 图谱页国内风格收口规格（画布层次/节点描边/边标签中文化默认隐藏/工具栏归组/tag 化/去 GitHub/时间轴双标签修复）

- 日期：2026-11-24
- 状态：已获用户批准（七项走查呈现，用户选方案一并确认设计）
- 背景：页头合一批（3b9c092）后用户走查"还是有点怪怪的"——以国内中后台风格（AntD/Arco/TDesign/飞书系）为基准的七项诊断。

## 诊断结论（改前基线）

1. 画布纯白+细网格，与白卡头/白页融为一体，无操作区层次感。
2. 节点实心彩底+深字（旧徽章感，对比度差）。
3. 边标签 snake_case 英文（invested_in）沿边旋转、密集交叠，与全中文界面混杂。
4. 左下工具栏三截竖排（魔棒/形状组/缩放组），间距不一。
5. "布局收敛中"裸文本混在卡头右段。
6. 顶栏 GitHub 图标（国内管理后台非常规元素）。
7. 时间轴浮条双"2026"重复标签。

## 设计（全部纯样式/展示层，零业务逻辑）

### §1 画布层次（B1）

- 画布容器底色：亮色 `#F7F8FA` 档（或等效 --color-bg 档灰）；暗色随暗档令牌深一档。
- 网格：细线改**点阵**（CSS radial-gradient 点，12-16px 间距，ink-3 低透明度）。
- **sigma 背景同步**：sigma（WebGL）自带背景填充——侦察 graphCanvas 相关配置，把 sigma backgroundColor/clearColor 设透明或与容器同色，否则容器底色被盖。
- 暗色主题两态都要走查。

### §2 节点白底描边（B2）

- sigma 自定义 node program（侦察绘制文件定锚）：实心彩底+深字 → **浅底（亮色主题白/极浅彩，暗色主题深灰）+ 1.5px 彩描边 + 彩字**（暗色亮字）。
- hover/选中反转实心（选中高亮语义保留）。
- pill 形状/圆角/尺寸不变。

### §3 边标签中文化+默认隐藏（B3）

- 谓词键中文映射表（前端常量，展示层）：`invested_in→投资` 等演示数据已知键全量映射；未知键 fallback 原文显示。
- 默认隐藏边标签（sigma settings.renderEdgeLabels=false 或等价机制）。
- 显示时机：hover 该边 / 钉住事实时显示该边中文标签（浅灰小字、不旋转；以 sigma 机制或浮层实现，实现者按现状机制择形）。
- 开关：卡头行2"边样式"弹层内加"显示全部标签"开关（默认关，开即全量显示中文标签）。
- i18n：新文案（显示全部标签等）进 zh/en 字典。

### §4 工具栏归组（B4）

- 左下三截 ToolTower 合并为一个 ToolTower：`[魔棒] |ToolDivider| [orbit/lasso/pack] |ToolDivider| [zoom in/zoom out/fit]`；按钮零增删。

### §5 布局收敛中 tag 化（B5）

- 卡头行1 裸文本改浅色 tag：primary-soft 底 + 旋转 spinner 小图标 + 文案；`v-if="stabilizing"` 语义不变。

### §6 顶栏去 GitHub（B6）

- lay-navbar 移除 GitHub 图标按钮（含 tooltip/点击行为；如有下拉"关于"收纳则收纳，否则直接删）。

### §7 时间轴双"2026"修复（B7）

- time-scrubber.tsx：排查起止年份相同/相邻时两端标签都渲染的成因 → 相等（或同月粒度收窄）时只显示单一标签或合并为区间显示；不改动 scrub 交互逻辑。
