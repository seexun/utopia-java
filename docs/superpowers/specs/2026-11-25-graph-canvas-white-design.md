# 图谱画布回归纯白规格（撤销画布灰底与点阵，方案 A）

- 日期：2026-11-25
- 状态：已获用户批准（三方案呈现 A/B/C，用户选 A）
- 背景：容器层次修正批（0cb9492）落地后用户仍觉"灰色背景太突兀"。量化后画布色 `#FAFBFC` 与卡头白仅差 5 阶——突兀感非底色明度差所致，而是点阵密度（透明度 ×3）+ 外框/卡头线双重描边把画布"框"成灰盒子。两轮反馈均指向灰框边界感，方案 A 直接消灭灰：画布与卡头同为白底，仅靠卡头分隔线区分。

## 设计

### §1 画布底回白

- `--color-canvas` 亮档 `#fafbfc` → `#ffffff`（与 `--color-card` 同值）；暗档 `#161616` → `#212121`（与卡暗档同值）。双源同步（tokens.scss :root/html.dark + tailwind.css 亮/html.dark）。
- 令牌本身保留（不删）：画布底是独立语义位，将来想再给画布上色只改令牌一处；注释更新为"当前与卡面同值"。
- `graphVisuals.ts`：`CANVAS_BG` 初值 `#ffffff`；摊平纸底 `LIGHT_GROUND_RGB` 回 `"255,255,255"`；单测 `graphVisuals.test.ts` 期望值随之更新（176,120,20 @0.6 摊在 255 白底 = 208,174,123）。

### §2 撤点阵

- `drawWorldGrid` 删除点阵绘制段（`GRID_*` 常量、层级换档、撒点循环）——函数仅保留画布尺寸同步 + 铺底色（白）。相机 `updated`/`resize` 仍调用它（尺寸变化时底色重铺），无行为损失。
- 网格层 canvas 保留（它是底色载体，sigma WebGL 层透明）。

### §3 外层卡恢复实体感

- 上一批把卡片改成透明+去阴影（为的是露出灰画布做两段式）——画布回白后两段式不再成立，卡片恢复 `.card` 默认（白底+细边+阴影），即撤销 `.graph-canvas-card` 的 `background-color: transparent; box-shadow: none` 两条覆写。
- 卡头 `bg-card` 保留（无害，卡头与卡身同白）；卡头底部分隔线保留（区分工具区与画布的唯一线条）。

### §4 本体页

- 共用绘制层自动跟随（画布回白、无点阵），本体页卡结构不动。

## 验收

1. 画布像素实测：亮 `255,255,255`、暗 `33,33,33`；卡片背景 `rgb(255,255,255)`（恢复实体）；画布任意位置无点阵像素（取样 5×5 区域方差为 0 或全白）。
2. 1280/1920 × 亮/暗 四截图目验：画布与卡头同为白、仅一条卡头分隔线、无灰雾无框中框。
3. `pnpm typecheck` + `pnpm test`（425）+ `build:prod` 绿；console 零 error；双 smoke 零退化。
4. 本体页抽验：画布白、无点阵。

## 不做的事

- 不动节点/边样式（白底描边彩字是上上批成果，保持）；不动卡头内容；不做方案 B/C；不动其它页面。
- 净效果 = 回到「国内风收口批之前」的画布底 + 保留该批的节点/边标签/工具栏等其它六项成果。
